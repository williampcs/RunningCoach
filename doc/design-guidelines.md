# Zone2Mate 設計準則（v1 提案）

2026-10-27 協調 session 提出（規格 12.28）；使用者看過、決定之後再改狀態。有圖的版本：協調 session 發布的「Zone2Mate 設計準則」頁（只有使用者看得到），這份文件是給開發用的文字版，兩者內容一致。

使用者的期望（原話）：「儘量看上去直覺，不依賴過多的文字做解釋，能用圖示解決就不要文字，必要的大段落文字要注意排版或考慮折疊，各個分頁的 UIUX 盡可能統一風格。」

## 五個原則

1. **一眼回答一個問題**：每個區塊只回答一件事（今天練什麼、這趟怎麼樣、還差多少）。
2. **圖示和數字先說**：能用圖示、色條、數字表達的就不寫句子；文字只補圖示說不清的。
3. **一塊一個主要動作**：每張卡最多一顆實心按鈕，其他降級成外框或文字按鈕。
4. **同一種東西長一樣**：課、紀錄、賽事在每一頁都用同一張卡、同樣的顏色和位置。
5. **長的說明先收起來**：超過兩行的說明收進「細節」或 ⓘ。

## 基礎（寫成 `styles.css` 的變數，新的畫面只用這些）

- 字級五級：數字 28／粗（時間、距離、心率等主要數字，`tabular-nums`）、標題 20／粗、小標 16／中粗、內文 15、輔助 13／淡色。現在的樣式表有 20 種字級，逐步收斂。
- 間距：4、8、12、16、24、32。同一行 8、卡片裡的區塊 12、卡片內距與畫面邊距 16、卡片之間 12、頁面的大段落 24–32。
- 圓角：8（欄位、標籤）、12（卡片）、全圓（按鈕、徽章）。
- 顏色：一種顏色只有一種意思。
  - 主色（teal）：主要按鈕、選中、今天。
  - 強度：低（teal）、中（amber）、高（coral）。課表與紀錄裡的顏色一律代表強度；**運動種類用圖示分，不用顏色分**（現在騎車用藍色，要改）。
  - 賽事：粉紅。
  - 狀態：達成用打勾（綠），沒做、休息用灰色，**不用紅色**（「一長串 DNF 會讓人挫折」，課表是建議不是考核）。
  - 危險（紅）：只給刪除、重設。
- 圖示：一套線條圖示取代 emoji（Lucide，ISC 授權，只把用到的 SVG 打包進來，不從 CDN 載入，CSP 照舊）。線條 2px；分頁 22、行內 20、標籤裡 14。跑步用 footprints、騎車 bike、肌力 dumbbell、游泳 waves、賽事 flag、身體狀況 heart-pulse、休息 moon。只有圖示、沒有字的按鈕只留給 ✕、?、齒輪、›，其他的旁邊都要有字；純圖示的按鈕要有 `aria-label`。

## 元件

- **按鈕**：主要（實心，一塊最多一顆）→ 次要（外框）→ 文字（不重要的、取消）。危險動作紅字並再確認。高度至少 44。按鈕上的字用動詞、六個字以內。
- **卡片**：一種卡片（底色、細框、圓角 12、內距 16）；卡片裡不套卡片，分區用細線或間距。
- **列表的一列**：左邊圖示，中間標題加一行副標，右邊數字、狀態或 ›。
- **標籤（chip）**：只放屬性，最多三個，不重複標題已經寫的。
- **收起的細節**：全 App 同一個樣子：› 加「細節」或「為什麼」。
- **提示**：存好了、同步完成用畫面下方的小提示，三秒後消失；錯誤寫在出錯的欄位旁邊並說怎麼修；要使用者動手的警告才用整條色塊。
- **表單**：標籤在欄位上面；說明最多一行小字，多的放 ⓘ；很少改的（模型名稱、思考強度）收進「進階」。

## 文字

- 標題十二個字以內；副標一行；說明兩行以內，超過就收起。
- 數字：距離到小數一位（常見的距離寫「半馬」「全馬」「10 km」）；時間 1:05:30 或 45 分；配速 5:30/km；日期 10/27（二），今天、明天直接寫。
- 一句最多一組括號，不疊括號。
- 用跑者會說的話，不用內部的詞（供應商、Rolling Window 之類）。

## 各頁套用（範例在設計準則頁）

1. 今天的重點：三列（身體狀況、賽事、今天的課），每列最多一顆主要按鈕；同一天的課合成一列；「知道了」統一成 ✕；步驟留在課表頁（9.4 工作單「「今天的重點」看板整理」）。
2. 課表的一堂課：運動圖示＋標題＋副標、最多兩三個標籤、一條強度條表示整堂課的結構（下面一行標暖身、主課、緩和），目的與說明收在「細節」，說明只出現一次。
3. 運動回報：標題就是問題（「哪一趟？」），活動用列表的一列，體感用 1–10 十格點選（下面標「很輕鬆／普通／全力」），一句話的感受，一顆「存起來」。
4. 設定：第一層是清單（AI 教練、訓練紀錄、多裝置同步、密碼鎖、天氣……），右邊是狀態，點進去才是欄位；很少改的收進「進階」；「資料會送到哪裡」改成 ⓘ。
5. 底部分頁：線條圖示＋兩個字（對話、回報、紀錄、計畫、選手）。

## 每次改畫面前的檢查

- 每張卡最多一顆實心按鈕。
- 沒有新的字級、間距或圓角。
- 沒有 emoji；圖示旁邊有字（✕ ? 齒輪 › 例外）。
- 超過兩行的說明收起來了。
- 數字和日期照格式寫。
- 同一種東西和別頁長一樣。
- 沒有疊在一起的括號。
- 手機與電腦、淺色與深色都截圖看過。
